# KERİM design references

These standalone files preserve user-approved interface designs before production
implementation. They are visual source material, not active KERİM routes.

## Preservation rule

Do not overwrite an approved reference while implementing it. Copy its layout into the
production templates and keep the reference unchanged. If the design itself changes,
add a new versioned file and retain the previous one in Git history.
