# UZAKTAN interface designs

These files are the durable visual references for the UZAKTAN remote dashboard.
They describe interface behaviour only; they do not send commands to a car.

Open `uzaktan-dashboard.html` through a local HTTP server rooted at the repository.
It loads icons from the preserved Reicon source under `Secondary/`.

Current shell:

- compact icon rail;
- motorless-test ready and running states;
- motor-test warning and five-second cancellable countdown;
- lane-test camera/log layout;
- remote-driving layout;
- run-log and vehicle-file views.
